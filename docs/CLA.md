# SwarmCore 贡献者许可协议（CLA）

> 本协议适用于向 SwarmCore-Sim 仓库（https://gitee.com/admin_0c00/0c00_ws）提交代码、文档、设计或其他内容（统称"贡献"）的个人或组织。
> 向本仓库提交 Pull Request、补丁或以其他方式递交贡献，即视为你已阅读并同意本协议全部条款。
> 本文不构成法律意见；如代表雇主提交，请确认你已获得雇主授权。

**协议双方**：贡献者（"你"）与 零创无穷（成都）科技有限责任公司（"我们"/"公司"）。

## 1. 定义

- **贡献**：你以任何形式（代码、文档、配置、美术资源、issue 中的补丁建议等）有意提交给我们、用于纳入 SwarmCore 项目的原创作品。
- **项目**：SwarmCore-Sim 仓库及其后续版本、衍生产品（含商业双轨交付物）。

## 2. 著作权许可

你保留对你贡献的著作权。你就每项贡献授予我们**永久的、全球范围的、非排他的、免费的、不可撤销的**许可，包括：

1. 使用、复制、修改、公开表演、公开展示、再分发你的贡献及其衍生作品的权利；
2. **再许可（sublicense）权利**：我们可以将你的贡献按项目对应模块的开源协议（GPL v3 / LGPL v3 / CC BY-NC 4.0）授权给公众，也可以将其纳入公司的**商业闭源交付物**另行授权（即"双许可"）；
3. 将你的贡献与公司或第三方的其他作品合并的权利。

**设置本条款的原因**：项目核心代码采用 GPL v3 保护社区不被闭源白嫖；双许可权利使公司能向需要闭源商用的企业出售商业许可证（Qt、MySQL 的经典模式），收入反哺开源迭代。没有统一的再许可权利，项目将无法双许可，也无法在未来必要时统一升级许可证版本。

## 3. 专利许可

你就每项贡献授予我们及项目的所有用户**永久的、全球范围的、非排他的、免费的、不可撤销的**专利许可，覆盖你的贡献本身或贡献与项目结合时必然落入的、你有权许可的专利权利要求，包括制造、使用、销售、许诺销售、进口该贡献。

若你针对任何人就项目或你的贡献提起专利诉讼（含反诉），你依据本协议及项目开源协议获得的专利许可自起诉之日起终止。

## 4. 你的声明与保证

提交每项贡献时，你声明：

1. 该贡献是你的原创作品，或你已获得提交所需的充分授权；
2. 据你所知，该贡献不侵犯任何第三方的著作权、专利、商标或其他权利；
3. 若贡献系职务作品，你的雇主已放弃相关权利或已书面授权你提交；
4. 若贡献包含第三方代码/素材，你已在提交中明确标注其来源与许可证，且其许可证与项目协议兼容。

## 5. 无担保与责任

你的贡献按"现状"提供，不附带任何明示或默示担保。在法律允许的最大范围内，你不对因贡献引起的任何损失承担责任。

## 6. 无义务

我们没有义务使用、合并或保留你的任何贡献；对未合并的贡献不承担责任。

## 7. 生效方式

以下任一行为均视为签署本协议：

- 向仓库提交 Pull Request / 补丁；
- 在提交信息、PR 描述或 issue 中明确表示同意；
- 与我们签署纸质或电子版本协议。

- 本协议适用中华人民共和国法律；争议由公司所在地有管辖权的人民法院管辖。
